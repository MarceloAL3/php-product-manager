# 🛒 PHP Product Manager

Sistema de gerenciamento de produtos desenvolvido com PHP 8+, PostgreSQL, PDO e JWT.

## 🚀 Tecnologias

- PHP 8+
- PostgreSQL
- PDO
- JWT
- Composer
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Cadastro de usuários
- Login
- Autenticação com JWT
- Proteção de rotas
- Cadastro de produtos
- Listagem de produtos
- Atualização de produtos
- Exclusão de produtos
- Busca de produtos
- Validação de dados
- Senhas protegidas com password_hash
- API REST
